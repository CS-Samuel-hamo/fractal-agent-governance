# Demo 2: Fractal Decomposition

This demo shows controlled recursive decomposition for a cross-surface feature.

Task:

> Add branch node status summary across backend API, domain logic, tests, and docs.

This is not ordinary subtask splitting. Each branch owns paths, provides outputs, consumes dependencies, and has acceptance criteria. The parent aggregates branch results before integration.

Governance properties shown:

- `max_depth`: recursion is bounded.
- `needs_decomposition`: only complex branches split further.
- Parent aggregation: objective, dependency, ownership, risk, and integration matrices.
- Model routing: decision work and execution work can use different model layers.

All paths are toy paths and do not refer to a real repository.
