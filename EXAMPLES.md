# Examples

## Documentation Preview

```powershell
agent "add a README troubleshooting note"
```

## Documentation Apply

```powershell
agent "fix README typo" --apply
```

## Small Code Preview

```powershell
agent "add one unit test for the local utility module"
```

## Check Status

```powershell
agent status
```

## Preview Undo

```powershell
agent undo
```
