# Community Roadmap

## Good First Issue

- Improve wording in toy demos.
- Add small eval cases for common DTO/schema/mapper changes.
- Add screenshots or GIFs for existing walkthroughs.

## Docs

- Expand quickstart for first-time Zoo Code users.
- Add diagrams for obligation ledger status transitions.
- Add a glossary for governance terms.

## Eval Cases

- Add cases for security review.
- Add cases for public API compatibility.
- Add cases for migration and rollback obligations.

## Zoo Adapter

- Improve package metadata.
- Add dry-run install documentation.
- Add adapter compatibility notes.

## Roo Adapter

- Map modes, rules, skills, and commands to Roo concepts.
- Document what cannot be mapped directly.
- Build a minimal toy adapter proof of concept.

## Dashboard

- Prototype a local static dashboard for obligation status.
- Show branch tree, path locks, and merge queue state.
- Avoid any requirement for external services.

## GitHub Action

- Keep validation lightweight.
- Add schema checks for eval cases.
- Add secret-pattern scanning without printing values.

## Worktree Runtime

- Improve path lock examples.
- Add merge queue conflict scenarios.
- Add examples for serial final integration.

## Governance Metrics

- Define completion quality metrics.
- Track open obligations by category.
- Track escalation and fallback frequency.
