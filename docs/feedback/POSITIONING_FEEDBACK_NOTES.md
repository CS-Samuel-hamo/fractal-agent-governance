# Positioning Feedback Notes

Track whether users understand the product correctly.

## Desired Understanding

- AI Project Operator
- Project Map-backed Autopilot
- Project-level progress, not task-level prompt execution
- Codex, Claude Code, local scanner, mock, and dry-run are workers
- Release and PR workflows generate local drafts, not remote PRs

## Confusion Markers

- "Is this just Codex?"
- "Why not use Claude Code directly?"
- "Is this a GitHub PR bot?"
- "Is this an enterprise governance system?"
- "Where is the project map value?"

## Response Pattern

When confusion appears, update docs and community copy before adding features.

Keep the sentence:

> Give it a project. It keeps moving it forward.
