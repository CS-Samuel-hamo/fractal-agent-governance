# Integration Candidate Report

The integration candidate report is stored at `.zoo-agent/runs/<run-id>/integration-candidate-report.json` and `.md`.

Verdicts:

- `INTEGRATION_CANDIDATE_READY`
- `INTEGRATION_TESTS_FAILED`
- `INTEGRATION_CONFLICTS`
- `NEEDS_PARENT_REAGGREGATION`
- `HUMAN_DECISION_REQUIRED`

The report is review evidence only. It is not merge authorization.
