# Architecture

Fractal Agent Governance Runtime adds an explicit governance layer around AI coding agent execution.

Core flow:

1. A goal starts a run.
2. The project profile describes local constraints and surfaces.
3. The obligation ledger captures explicit and implicit work.
4. The fractal branch tree decomposes complex work under depth and ownership controls.
5. GPT decision layers handle planning, review, escalation, and aggregation.
6. DeepSeek execution layers handle bounded implementation tasks.
7. Quality, review, and integration gates check evidence before completion.
8. Worktree runtime isolates parallel exploration.
9. Merge queue serializes integration.
10. Learning loop feeds outcomes back into future governance decisions.
