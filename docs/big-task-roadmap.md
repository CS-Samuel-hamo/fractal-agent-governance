# Big Task Roadmap

0.5.0 adds a dry-run-first governance layer for large tasks and large projects.

0.4.x remains responsible for small task delivery: fast path, Codex worker execution, scope guard, delivery outcome, backend health, goal/loop, and bounded README/docs/code edits.

0.5.0 is responsible for big task readiness, big task contracts, semantic resource maps, leaf task contracts, task readiness gates, parent aggregation, integration worktrees, and staged execution policy.

Root big tasks must never be sent directly to Codex actual execution. The only executable unit is a ready low-risk leaf task, and actual leaf execution requires explicit user confirmation.
