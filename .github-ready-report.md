- Codex CLI execution is treated as an execution backend and may run in dry-run or placeholder mode when Codex CLI is not installed.
- Parallel execution remains conservative by design. Unknown shared resources deny parallel execution instead of guessing.
- Governed path currently records governance gates and review readiness; it does not auto-merge or auto-push.
- Rollback is intentionally plan-first. Destructive recovery actions require explicit confirmation and isolated worktree checks.
- Zoo Code UI remains optional and is not required for CLI runtime operation.
