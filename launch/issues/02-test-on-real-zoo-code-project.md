# Test the pack on a local Zoo Code toy project

Labels: `feedback`, `zoo-adapter`

## Goal

Try the governance pack on a small toy Zoo Code project and report what is confusing, too strict, or too loose.

## What To Test

- `/agent-run` flow.
- Obligation Ledger behavior.
- Quality gate behavior.
- Worktree scheduling docs.

## Acceptance Criteria

- Feedback uses toy examples or redacted summaries.
- No secrets, tokens, real logs, or private paths are shared.
- The report explains whether the workflow is useful as a Zoo Code governance pack.

## Non-goals

- Do not test on confidential business projects.
- Do not upload private run records.
