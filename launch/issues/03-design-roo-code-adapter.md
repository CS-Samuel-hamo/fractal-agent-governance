# Design a Roo Code adapter mapping

Labels: `adapter`, `design`, `roo`

## Goal

Draft a design for mapping this Zoo-first governance pack to Roo Code concepts.

## Questions

- How should modes map?
- How should rules map?
- How should skills map?
- How should commands map?
- Which eval cases are portable?

## Acceptance Criteria

- Design stays adapter-focused and does not require core project rewrites.
- Unsupported concepts are explicitly listed.
- Proposal includes at least one toy workflow.

## Non-goals

- Do not implement the adapter before the mapping is reviewed.
- Do not include real project data.
