# Build a local dashboard prototype

Labels: `dashboard`, `prototype`

## Goal

Create a local-only prototype dashboard that visualizes governance artifacts.

## Suggested Views

- Obligation Ledger status summary.
- Fractal branch tree.
- Path locks.
- Merge queue.
- Gate status.

## Acceptance Criteria

- Uses toy fixture data.
- Does not require API keys.
- Does not require external services.
- Includes screenshots or a short GIF if UI is added.

## Non-goals

- No cloud backend.
- No telemetry.
- No real project run logs.
