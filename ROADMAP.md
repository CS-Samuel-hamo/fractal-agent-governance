# Roadmap

## 0.99 Public Alpha Packaging

Current focus:

- freeze public positioning
- clean public docs
- package a safe demo project
- audit for local path, secret, and unsupported claim leakage
- keep the public CLI simple

## 1.0 Public Release

Current public alpha focus:

- stronger install experience
- stable public command behavior
- clearer release readiness defaults
- more robust local Cockpit examples
- broader fixture coverage

Current tag target: `v1.0.0-alpha.1`.

## 1.1 Stronger Sessions And Cockpit

Planned focus:

- clearer session recovery
- richer progress timeline
- better attention summaries
- improved undo explanation

## 1.2 Optional GitHub Integration

Potential future work:

- optional authenticated GitHub workflows
- user-confirmed branch and PR creation
- explicit network and token authorization

This is not part of the current alpha.

## Later Team / Enterprise Tracks

Possible later work:

- team policy packs
- shared project learning
- enterprise secrets boundaries
- hosted dashboards

No cloud service or account system is included in the current alpha.
