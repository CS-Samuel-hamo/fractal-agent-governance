# Product Positioning

## One-line Description

AI Project Operator.

## Tagline

Give it a project. It keeps moving it forward.

## Core Difference

Project-level Autopilot, not task-level coding agent.

Agent Runtime is built around a Project Map and durable sessions. It tracks project state, chooses the next project-level action, coordinates available workers, updates progress, and prepares release or PR-ready artifacts.

## What It Is

- A local-first project operator for software repositories.
- A Project Map-backed autopilot for ongoing project work.
- A Cockpit-driven way to see project progress, next actions, risks, and recovery points.
- A release preparation layer that creates local PR and release artifacts.
- A worker-agnostic system where coding tools are execution workers, not the product.

## What It Is Not

- Not a Codex wrapper.
- Not a Claude Code replacement.
- Not a generic AI coding CLI.
- Not an agent framework for building arbitrary agents.
- Not a GitHub PR bot.
- Not an enterprise governance tool.

## Why Not Just Codex Or Claude Code?

Codex and Claude Code are excellent task-level workers. Agent Runtime focuses on the project layer above workers:

- What is this project?
- What is the current state?
- What should happen next?
- What has already been tried?
- What needs attention?
- What is needed before release?

The product does not claim to code better than any worker. It coordinates project progress across workers and artifacts.

## Target Users

- Solo builders preparing projects for public release.
- Maintainers who want a local project progress loop.
- AI-first teams that want project-level state instead of isolated prompts.
- Developers who want local PR and release drafts without remote automation.

## Main Use Cases

- Prepare a repo for public alpha.
- Maintain an ongoing project readiness map.
- Run a long session toward a project goal.
- Generate a local Cockpit for project status.
- Produce PR drafts, release notes, changelog drafts, and action plans.

## Public Promise

Agent Runtime helps a project keep moving locally. It does not replace human judgment, code review, release ownership, or deployment control.
