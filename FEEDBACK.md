# Feedback

The public alpha is looking for product feedback, not benchmark claims.

## Best Feedback To Share

- Did the Project Map help you understand the project?
- Did the session choose a useful next action?
- Did Cockpit make progress clear?
- Did release / PR drafts save time?
- Where did the first run feel confusing?
- What stopped you from trusting the next action?

## Please Remove Before Sharing

- secrets
- API keys
- `.env` contents
- raw logs
- local absolute paths
- private source code snippets
- `.zoo-agent/` artifacts unless you reviewed and sanitized them

## Good Issue Templates

Use the GitHub issue templates for:

- first run feedback
- Project Map quality
- Autopilot session feedback
- Cockpit feedback
- release / PR workflow feedback
- bug reports
- feature requests

## Product Framing

Agent Runtime is an AI Project Operator. Codex, Claude Code, and local tools are workers. The product is the project operator.
