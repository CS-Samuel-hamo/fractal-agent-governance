# Known Limitations

Version: `v1.0.0-alpha.1`

- This is a public alpha.
- It does not create remote GitHub PRs.
- It does not call GitHub APIs.
- It does not push, merge, deploy, or create remote releases.
- It does not provide cloud sync, telemetry, accounts, or team features.
- Claude/local actual execution is not claimed as generally supported unless a real local adapter is detected.
- Local learning is advisory and does not train a model.
- Human review is required before publishing or deploying.
- Some sessions may pause with needs-attention when a worker is unavailable or a task is risky.
