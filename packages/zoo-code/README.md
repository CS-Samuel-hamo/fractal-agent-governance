# Zoo Code Adapter Package

This package contains the Zoo Code adapter.

It is intended to be installed as a global governance pack, not copied into business repositories.

Recommended usage:

1. Run dry-run or validation first.
2. Install globally with the provided installer only after review.
3. Reload VS Code / Zoo Code after install.
4. Configure provider profiles separately in your local tool environment.

Do not commit secrets, real project logs, or local run records into this package.
