# Adaptive Fast Path Policy

Adaptive fast path prevents low-risk work from paying the cost of full fractal governance.

## Level 0

Use fast path for micro edits involving 1 to 3 files, explicit changes, and no architecture, dependency, database, schema, auth, security, PII, payment, public API, or shared-type impact.

Required:

- high-risk guard
- optional Codex or DeepSeek execution
- scope guard
- diff summary

Skip by default:

- full fractal decomposition
- multi-role flow
- curator update
- eval suite
- release readiness
- operational readiness

## Level 1

Use fast path for routine coding, small bug fixes, local modules, analogous implementation, and expected 3 to 10 file changes.

Required:

- mini obligation check
- Codex preferred executor unless DeepSeek is explicitly selected
- targeted tests
- scope guard
- mechanical review

Fast path is disabled when any Level 2, Level 3, or Level 4 trigger is present.
