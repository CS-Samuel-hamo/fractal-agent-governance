# Zoo Codex Hybrid Eval

The hybrid eval measures whether Zoo keeps governance quality while Codex CLI accelerates bounded implementation.

Cases must include:

- simple bugfix
- small refactor
- add field
- API behavior change
- test-only task
- docs-only task
- shared type change
- Proc/data-source mismatch
- cross-module feature
- security-sensitive change

The expected win is not raw speed alone. A successful hybrid run must preserve scope, evidence, review quality, and final governance ownership.
