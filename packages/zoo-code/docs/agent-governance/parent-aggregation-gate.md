# Parent Aggregation Gate

Parent aggregation checks whether child branches satisfy the parent objective before integration.

Required matrices:

- Objective Coverage Matrix.
- Dependency Matrix.
- Ownership / Resource Matrix.
- Risk Matrix.
- Integration Matrix.
- Diagnostics Aggregation.
- Goal Coverage.
- Open obligations.
- Open risks.

Passing child diagnostics is not sufficient. Aggregation diagnostics and merge candidate diagnostics must also pass.
