# Product Intake Template

## User Intent
State the user-visible or business outcome.

## Success Criteria
List measurable criteria. Each criterion must map to evidence.

## Non-Goals
List behaviors, modules, users, or integrations that are explicitly out of scope.

## Constraints
Include deadlines, compatibility, risk tolerance, data rules, and release constraints.

## Open Questions
Mark unknowns. Do not invent answers. Unknowns that block implementation must escalate.
