# New Project Onboarding

Use Project Bootstrap for an empty folder that should become a new governed project.

## Steps

1. Open empty folder.
2. Run `Agent: Bootstrap Project`.
3. Enter project goal/stack if known.
4. Generate governance shell.
5. Commit initial governance shell.
6. Ask Zoo/GPT to plan first tasks.
7. Give leaf tasks to Codex Worker.

Bootstrap may initialize Git and create README, AGENTS.md, `.gitignore`, `.zoo-agent/project-profile.json`, `.zoo-agent/bootstrap-report.md`, and an initial `TASKS.md` draft. It does not create business modules.
