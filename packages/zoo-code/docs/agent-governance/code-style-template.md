# Code Style Template

Record stack, formatter, lint, typecheck, test. TypeScript: strict typing, no any expansion, schema/DTO sync, async errors, barrel policy. Python: type hints, ruff/mypy/pytest, pydantic/dataclass boundary, sync/async. Go: context, error wrapping, interface ownership, table tests. Java/Kotlin: layering, exception mapping, Spring boundary, test slices. Rust: Result/error, ownership, feature flags, tests. Unknown values stay `unknown`.
