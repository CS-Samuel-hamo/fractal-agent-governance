# Zoo as Governance Layer

Zoo owns durable governance state and transitions. It manages:

- goal contract
- task board
- governance intensity classification
- obligation ledger
- branch state and fractal decomposition
- worktree map and scheduling
- path locks and resource locks
- progress, redirect, and resume
- quality gate and review gate
- parent aggregation and merge queue
- lessons, memory, evals, and metrics

Zoo must receive every Codex result before review or integration. The result is evaluated against task scope, acceptance criteria, evidence, and governance level.

Level 0 and Level 1 tasks use adaptive fast path unless trigger signals appear. Level 2+ work keeps stronger governance. Level 3 and Level 4 work retain fractal decomposition, worktree isolation, approval gates, and parent aggregation.
