# One-Click Project Setup

Project Bootstrap is available through:

- `Agent: Bootstrap Project`
- `Agent: Open Bootstrap Report`
- `Agent: Re-run Bootstrap`
- `Agent: Commit Bootstrap Files`
- `Agent: Open Project Readiness`
- `/agent-bootstrap`

## Existing Projects

1. Open project root.
2. Run `Agent: Bootstrap Project`.
3. Review bootstrap report.
4. Apply safe files.
5. Commit bootstrap files if desired.
6. Start Level 0/1 task.

## New Projects

1. Open empty folder.
2. Run `Agent: Bootstrap Project`.
3. Enter project goal/stack if known.
4. Generate governance shell.
5. Commit initial governance shell.
6. Ask Zoo/GPT to plan first tasks.
7. Give leaf tasks to Codex Worker.
