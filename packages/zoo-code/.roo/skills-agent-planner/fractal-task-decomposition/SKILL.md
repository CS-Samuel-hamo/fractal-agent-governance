# Fractal Task Decomposition Skill
Use for complex tasks represented as recursive branch nodes.

## Procedure
Define parent objective, identify separable axes, create child branches only where the split reduces uncertainty or isolates risk, define child contracts, aggregation protocol, exit conditions, and integration sequence.
