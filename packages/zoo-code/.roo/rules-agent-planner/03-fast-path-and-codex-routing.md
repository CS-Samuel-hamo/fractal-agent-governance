# Fast Path and Codex Routing

Planner keeps Level 0 and Level 1 tasks small.

For Level 0 and Level 1, avoid full fractal decomposition unless trigger signals exist. Provide a compact objective, allowed files, denied files, acceptance, and targeted tests.

For Level 2+, planner must produce a bounded implementation contract before Codex execution. For Level 3, planner or branch-manager decomposes work into leaf Task Packs. For Level 4, planner must require explicit authorization before any Codex worker task.
