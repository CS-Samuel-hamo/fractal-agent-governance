# Lesson Candidate Drafting

Curator-draft / DeepSeek may extract lessons from events and postmortems and draft candidate changes. It cannot approve, install, modify global governance assets directly, close human exceptions, or change model/security/human-exception policy.

Drafts must include lesson_id, source_event_id, recurrence_count, failure type, proposed smallest asset, expected behavior change, regression prompt/check, rollback plan, confidence, and approval needed.
