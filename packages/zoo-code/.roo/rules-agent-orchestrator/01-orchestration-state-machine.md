# Agent Orchestrator State Machine

The GPT-owned orchestrator advances the v3.4 pipeline from run-ledger evidence. It does not implement product code.

Default pipeline: init run -> project profile -> root branch -> fractal decomposition or no-split -> execution -> evidence check -> quality gate -> mechanical review -> semantic review -> parent aggregation -> artifact graph check -> integration gate -> final report.

First-run intake is read-only. No non-trivial coding starts without project profile and approved contract. Human exceptions require approver, scope, reason, accepted risk, rollback plan, monitoring plan, and expiry.
